# dynamic_cover_for_SMM

Динамическая обложка сообщества ВКонтакте: на фон накладывается текущее время, картинка заливается как обложка паблика каждые N секунд.

## Запуск

```sh
pip install -r requirements.txt
export VK_TOKEN=...      # токен сообщества с правом «управление сообществом»
export VK_GROUP_ID=12345 # числовой ID группы
python vkcover.py
```

Необязательные переменные: `COVER_TZ` (по умолчанию `UTC`, напр. `Europe/Moscow`), `COVER_INTERVAL` (сек, 120),
`COVER_TEXT` (шаблон с `{time}` и `{tz}`), `COVER_COLOR` (hex, напр. `#c10020`), `COVER_TEXT_POS` (`x,y` — центр верха текста, по умолчанию `1035,40`), `COVER_TEXT_MAX_WIDTH`, `COVER_TEXT_MAX_SIZE`, `COVER_BACKGROUND`, `COVER_FONT`.

## Размер

Обложка ВК — **1590×530**. Фон любого размера автоматически масштабируется и обрезается по центру до этого формата
(лучше сразу делать фон 1590×530). Текст автоматически уменьшается, чтобы влезть в `COVER_TEXT_MAX_WIDTH`. Важное держите в центре: в мобильном приложении видно ~1196 px по ширине.
